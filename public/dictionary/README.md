# Offline dictionary

`ecdict.json` is a 20,000-word subset of [ECDICT](https://github.com/skywind3000/ECDICT), selected by corpus frequency. Each entry is `[word, phonetic, Chinese translation, normalized part of speech]`.

The data is generated by `scripts/build_dictionary.py` from the ECDICT CSV. ECDICT and this generated subset are distributed under the MIT license; see `LICENSE`.

ECDICT is an offline English-Chinese dictionary assembled by skywind3000. This project only bundles a small frequency-filtered subset for instant word lookups; AI remains responsible for contextual meaning.
